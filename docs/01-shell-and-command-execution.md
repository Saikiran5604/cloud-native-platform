# Day 1 - Shell and Command Execution

## Objective

Understand what happens internally when a Linux command is executed.

## Concepts Learned

- Terminal vs Shell
- PATH Variable
- Executables
- Shell Builtins
- Environment Variables

## Commands Practiced

- echo $SHELL
- echo $PATH
- which
- type

## Key Takeaway

The shell searches directories listed in PATH to locate executables. Some commands such as `cd` are shell builtins because they must modify the shell process itself.
